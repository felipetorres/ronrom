# Ronrom

Jogo de gatinhos no navegador: encontre, conquiste e combine gatos num mundo aberto aconchegante.

**Jogue:** https://felipetorres.github.io/ronrom/

Este repositório guarda só a versão compilada que o GitHub Pages serve. Depois de aberto uma vez, o jogo funciona offline e pode ser instalado na tela inicial: no Android, pelo botão "Instalar" do Chrome; no iPhone, pelo Safari em Compartilhar → Adicionar à Tela de Início.

Para guardar o gatil, as moedas, as trocas entre amigos, a comida e o lugar onde você parou no mapa, o jogo cria uma conta anônima num servidor (Supabase, nos Estados Unidos). Não pede nome, e-mail nem telefone. Quem vincula o gatil a uma conta Google, em Vincular ao Google no menu, passa a ter no servidor também o e-mail, o nome e a foto que o Google informa. Os ajustes do menu (som, imagem e controles) ficam só no aparelho. Para apagar a conta e tudo o que ela guarda, inclusive o vínculo com o Google, use Novo jogo na tela inicial.

Terceiros: three.js (MIT, cabeçalho no próprio arquivo) e as fontes Baloo 2, Nunito e DM Mono (SIL Open Font License, textos em `fonts/`).

Os sons de gatos são gravações em domínio público (CC0 1.0) publicadas no Freesound.
